Alat dan Bahan Perancangan Jaringan

Sebelum memulai merangkai jaringan dan kabel, pastikan Anda telah menyiapkan perangkat keras berikut:

Kabel UTP

Media transmisi data jaringan komputer yang terdiri dari 4 pasang kabel lilit.

Konektor RJ45

Kepala penghubung kabel UTP yang dipasangkan pada kedua ujung kabel.

Crimping Tool

Alat untuk mengunci konektor RJ45 agar menancap kuat pada kabel UTP.

LAN Tester

Alat penguji konektivitas untuk memastikan susunan kabel terhubung dengan benar.

Kabel Stripper

Alat pengupas pelindung luar kabel UTP dengan presisi tinggi.

Cara Merangkai Kabel LAN Tipe Cross

Kabel tipe Cross-Over digunakan untuk menghubungkan dua perangkat yang sejenis (contoh: PC ke PC, Switch ke Switch, Hub ke Hub). Pada kabel cross, ujung pertama menggunakan standar T568A dan ujung kedua menggunakan standar T568B.

Susunan Warna Kabel Cross:

Nomor Pin Ujung 1 (Standar T568A) Ujung 2 (Standar T568B)
Pin 1Putih-HijauPutih-Oranye
Pin 2HijauOranye
Pin 3Putih-OranyePutih-Hijau
Pin 4BiruBiru
Pin 5Putih-BiruPutih-Biru
Pin 6OranyeHijau
Pin 7Putih-CokelatPutih-Cokelat
Pin 8CokelatCokelat

Langkah-langkah Pengerjaan:

  1. Kupas kulit luar kabel UTP menggunakan kabel stripper sepanjang kurang lebih 2 cm.
  2. Urai dan luruskan kabel-kabel di dalamnya, lalu susun warnanya sesuai urutan standar di atas.
  3. Ratakan ujung kabel menggunakan pemotong pada tang crimping agar sama panjang.
  4. Masukkan kabel secara perlahan ke dalam konektor RJ45 pastikan tembaga menyentuh ujung maksimal konektor.
  5. Masukkan konektor RJ45 ke dalam tang crimping, lalu tekan dengan kuat hingga terdengar bunyi klik.
  6. Uji hasil crimping menggunakan LAN Tester.

Menghubungkan 2 Laptop & Setting IP Address

Setelah kabel Cross terpasang antar kedua laptop, lakukan konfigurasi IP Address manual (Static) agar kedua laptop dapat saling mengenali dalam satu jaringan lokal (LAN).

Konfigurasi Laptop 1:

  • Buka Control Panel > Network and Sharing Center > Change adapter settings.
  • Klik kanan pada Ethernet, pilih Properties > Internet Protocol Version 4 (TCP/IPv4).
  • Masukkan data IP Address:
    • IP Address: 192.168.1.1
    • Subnet mask: 255.255.255.0

Konfigurasi Laptop 2:

  • Lakukan langkah serupa pada laptop kedua dengan IP Address:
    • IP Address: 192.168.1.2
    • Subnet mask: 255.255.255.0

Pengujian Koneksi (Ping Test):

Buka Command Prompt (CMD) di Laptop 1, lalu ketik perintah berikut:

ping 192.168.1.2

Cara Sharing File Menggunakan Win + Run

Untuk berbagi file antar laptop yang terhubung dalam jaringan LAN:

Langkah 1: Pengaturan Sharing di Komputer Sumber (Host)

  1. Klik kanan pada folder yang ingin di-share > Properties > tab Sharing > Advanced Sharing.
  2. Centang Share this folder > klik Permissions > centang Full Control.
  3. Pastikan Turn on file and printer sharing aktif di Advanced Sharing Settings.

Langkah 2: Mengakses Folder di Komputer Tujuan

  1. Tekan tombol
    Windows + R
    pada laptop kedua.
  2. Ketikkan IP address komputer sumber:
    3. \\192.168.1.1
  3. Tekan Enter untuk membuka dan mengambil file.
