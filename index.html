Peralatan & Komponen Utama

Instrumen standar industri untuk perakitan fisik jaringan komputer

Konektor RJ45

Konektor 8 pin modular untuk mengakhiri kabel UTP pada port Ethernet perangkat.

Tang Crimping

Peralatan mekanis untuk menekan pin konektor logam menembus kabel UTP.

LAN Tester

Alat uji kontinuitas listrik untuk memastikan urutan pin 1-8 berjalan tanpa hambatan.

Kabel Stripper

Pisau presisi pengupas jaket luar kabel UTP tanpa merusak isolasi kabel internal.

Kabel UTP Cat6

Unshielded Twisted Pair berkecepatan tinggi untuk transmisi data antar perangkat.

Panduan Merangkai Kabel LAN Tipe Cross

Standar penyusunan pin untuk koneksi langsung antar perangkat sejenis (PC ke PC / Switch ke Switch)

Komparasi Susunan Warna Kabel Cross

Kabel Cross menghubungkan standar T568A pada Ujung A dan standar T568B pada Ujung B untuk membalikkan jalur transmisi (TX/RX crossover).

Ujung A (T568A)
  • 1. Putih-Hijau
  • 2. Hijau
  • 3. Putih-Oranye
  • 4. Biru
  • 5. Putih-Biru
  • 6. Oranye
  • 7. Putih-Cokelat
  • 8. Cokelat
Ujung B (T568B)
  • 1. Putih-Oranye
  • 2. Oranye
  • 3. Putih-Hijau
  • 4. Biru
  • 5. Putih-Biru
  • 6. Hijau
  • 7. Putih-Cokelat
  • 8. Cokelat

Prosedur Eksekusi Crimping

  1. 1 Kupas isolator luar kabel UTP menggunakan Kabel Stripper sepanjang ±2 cm.
  2. 2 Urai lilitan kabel, luruskan, dan susun berdasarkan standar T568A dan T568B.
  3. 3 Potong rata ujung kabel menggunakan pemotong tang crimping agar posisinya sejajar sempurna.
  4. 4 Masukkan ke konektor RJ45 secara perlahan hingga tembaga menyentuh ujung depan.
  5. 5 Kunci kuat dengan Tang Crimping dan verifikasi menggunakan LAN Tester.

Topologi Hubungan 2 Laptop & Konfigurasi IP

Pengaturan alamat IP statis agar komunikasi peer-to-peer berjalan lancar

Laptop Utama Node 01
  • IP Address: 192.168.1.1
  • Subnet Mask: 255.255.255.0
  • Gateway: Not Required (P2P)
Laptop Kedua Node 02
  • IP Address: 192.168.1.2
  • Subnet Mask: 255.255.255.0
  • Gateway: Not Required (P2P)
Prosedur Windows IPv4 Config
  1. 1. Buka Control Panel > Network & Sharing Center.
  2. 2. Pilih Change adapter settings > Klik kanan Ethernet > Properties.
  3. 3. Pilih Internet Protocol Version 4 (TCP/IPv4) > klik Properties.
  4. 4. Masukkan konfigurasi IP Statis sesuai node masing-masing laptop.

Teknik File Sharing Menggunakan Shortcut Run

Metode kilat mengakses direktori komputer target via perintah Windows + R

Eksekusi Perintah Jaringan

Setelah koneksi kabel LAN dan IP Address terkonfigurasi dengan benar, Anda dapat langsung melakukan transfer atau mengakses file dari komputer rekan Anda tanpa perangkat tambahan.

// Contoh Akses dari Laptop 1 ke Laptop 2:

1. Tekan tombol Windows + R

2. Ketik perintah: //192.168.1.2 lalu Enter

Checklist Keamanan & Troubleshooting:

  • Pastikan Password Protected Sharing dinonaktifkan di pengaturan Advanced Sharing.
  • Uji koneksi jaringan menggunakan terminal CMD dengan perintah ping 192.168.1.2.
  • Pastikan profil jaringan tersetting sebagai Private Network.
